# Sweet Shop Management System

## Description
This is a full-stack Sweet Shop Management System project designed to manage sweet shop operations in an organized and user-friendly way. The project includes both frontend and backend components.

## Features
- Product / sweets display
- Shop management interface
- User-friendly frontend
- Backend integration
- Structured full-stack project setup

## Tech Stack
### Frontend
- HTML / CSS / JavaScript / React (edit according to your project)

### Backend
- Node.js
- Express.js

- `backend/` → Server-side logic
